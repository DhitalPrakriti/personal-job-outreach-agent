# Dify Agent Configurations

Store exported Dify agent/workflow DSL files here.

## Agents

| Agent | Model | Purpose |
|-------|-------|---------|
| Research Agent | Claude Sonnet | Web scraping, company research, news, pain points |
| Drafting Agent | Claude Sonnet | Personalized cold email generation |
| QA Agent | Claude Haiku | Spam check, tone, CAN-SPAM compliance |
| Classification Agent | Claude Haiku | Reply intent classification |
| Follow-Up Agent | Claude Sonnet | Context-aware follow-up drafts |

## How to Export

1. Open Dify Studio
2. Select app → Settings → Export DSL
3. Save YAML here
4. Commit to git
